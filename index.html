เลือกวิธีเริ่มต้นใช้งานของคุณ

(จำเป็นสำหรับการ sync ข้อมูล)

⚠️ ต้องการตั้งค่า Google Sheet เพื่อให้ใช้งานได้:

  1. เปิด Google Sheet ขึ้นมา
  2. ไปที่เมนู Extensions > Apps Script
  3. ลบโค้ดเก่าออกแล้ววางโค้ดนี้:
  4. กดปุ่ม Deploy > New Deployment
  5. เลือกประเภทเป็น Web App
  6. ตั้งค่า Who has access เป็น Anyone
  7. กด Deploy แล้วก๊อปปี้ Web App URL
  8. วาง URL ที่ได้ในช่องด้านบน

ใส่ Google App Script URL ที่เคยบันทึกข้อมูลไว้ ระบบจะดึงข้อมูลมาให้อัตโนมัติ

ลองใช้งานฟังกชันพื้นฐานได้ทันที ข้อมูลจะถูกเก็บเฉพาะในเครื่องนี้เท่านั้น
